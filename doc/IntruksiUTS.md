## INSTRUKSI UJIAN

1. Media Ujian Online: Microsoft Teams (Assignment & Forms)
2. Ujian bersifat kelompok.
3. Jika ditemukan pekerjaan ujian yang sama antar kelompok yang berbeda, maka nilai UTS = 0 (nol).
4. File yang dikumpulkan dalam bentuk Word (.zip). Setiap anggota kelompok wajib submit laporannya ke form UTS ini.

## SOAL

Proyek dikerjakan secara berkelompok dengan anggota 3–4 mahasiswa. Setiap kelompok bebas memilih aplikasi berbasis web serta bahasa pemrograman atau framework yang digunakan.

Aplikasi minimal memiliki:
- Dua halaman atau endpoint
- Dapat diakses melalui browser
- Menggunakan minimal satu environment variable
- Menghasilkan log ketika menerima request

Aplikasi tidak diwajibkan menggunakan database.

Setiap kelompok mengumpulkan:
- Source code aplikasi
- Containerfile/Dockerfile
- .containerignore/.dockerignore
- README.md berisi petunjuk build dan run
- Laporan proyek dalam format PDF
- Bukti image tersedia di container registry
- Video penjelasan dan demonstrasi proyek

Video penjelasan berdurasi sekitar 8–12 menit dan harus memuat:
1. Perkenalan anggota kelompok dan pembagian tugas
2. Penjelasan fungsi dan arsitektur aplikasi
3. Penjelasan bagian stateless dan stateful
4. Penjelasan isi Containerfile/Dockerfile dan .containerignore/.dockerignore
5. Demonstrasi proses build dan run menggunakan Podman/Docker
6. Demonstrasi port mapping dan environment variable
7. Demonstrasi penggunaan logs, inspect, atau exec
8. Penjelasan optimasi dan keamanan image
9. Bukti push dan pull image dari registry
10. Bukti aplikasi berhasil dijalankan dari image hasil pull
11. Penjelasan kendala yang ditemukan dan cara menyelesaikannya

Video harus memiliki suara yang jelas dan menampilkan terminal, aplikasi, serta hasil implementasi proyek yang dapat dibaca. Tautan video dapat dimasukkan ke dalam laporan proyek dan pastikan tautan video dibuat link public agar dapat diakses oleh dosen.
